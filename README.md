## 🎯 Description du Projet
Ce projet consiste en la conception et le développement d'un site web statique, réalisé dans le cadre de l'évaluation finale du module de Programmation WEB. Centré sur la thématique des avions de chasse militaires, ce site propose une exploration détaillée de leur histoire et de leurs caractéristiques techniques à travers une interface utilisateur interactive et responsive. L'objectif pédagogique principal est de démontrer l'acquisition et la maîtrise des standards fondamentaux du développement front-end.

## 🛠️ Technologies et Frameworks
* **🧱 HTML5** : Déploiement d'une structure sémantique rigoureuse (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`) afin d'optimiser l'accessibilité et le référencement.
* **🎨 CSS3** : Conception de l'interface graphique incluant l'utilisation avancée de Flexbox pour la mise en page, l'intégration d'animations personnalisées (`@keyframes`), et l'application des principes du Responsive Web Design.
* **⚡ JavaScript** : Programmation de l'interactivité côté client. Les scripts assurent la manipulation dynamique du DOM, la gestion des événements pour le filtrage de la galerie photographique, ainsi que la validation syntaxique des données du formulaire de contact.
* **📱 Bootstrap 5** : Intégration du framework pour l'utilisation de son système de grille fluide et l'implémentation rapide de composants d'interface adaptatifs.

## 📂 Architecture Logique
* 🏠 `index.html` : Point d'entrée de l'application (Hero page) intégrant des éléments textuels dynamiques.
* 📜 `histoire.html` : Modélisation sémantique de l'évolution chronologique des aéronefs.
* 📊 `technique.html` : Module de comparaison technique exploitant des composants visuels de type barres de progression.
* 🎯 `combat.html` : Interface dédiée à la présentation des systèmes d'armement, enrichie par des animations CSS simulant un balayage radar.
* 🖼️ `galerie.html` : Composant visuel interactif permettant le filtrage asynchrone des médias selon leur catégorie.
* 📝 `recrutement.html` : Formulaire de collecte de données intégrant des contraintes de validation natives (HTML5) et scriptées (JS).
* 💅 `style.css` : Feuille de style globale garantissant la cohérence visuelle de l'ensemble des vues.
* ⚙️ `script.js` : Fichier centralisant la logique applicative et les routines d'interaction utilisateur.
* 📁 `images/` : Répertoire contenant les ressources iconographiques et photographiques du projet.
